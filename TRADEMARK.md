The **Diffo** name and the Diffo logo are trademarks of Diffo.

The Diffo source code is licensed under the [Apache License 2.0](LICENSE) —
you are free to use, modify, fork, and redistribute the code, including
commercially. **The license covers the code, not the name** (Apache-2.0
§6 says so explicitly). This policy explains what you can and cannot do
with the Diffo name and logo.

## You may, without asking

- Use the name to truthfully refer to the project: "built on Diffo",
  "compatible with Diffo", "a plugin for Diffo".
- Keep the name in unmodified copies — packaging, mirroring, or
  redistributing official releases as-is.
- Use the name in articles, talks, tutorials, reviews, and comparisons.
- Fork the repository on GitHub with the fork's default repository name.

## You may not, without written permission

- Use "Diffo" (or a confusingly similar name — e.g. "Diffo Pro",
  "DiffoHub", "OpenDiffo") as the name of a modified version, a fork you
  distribute, or any derived product or service.
- Offer a hosted or managed service under the Diffo name or logo.
- Use the name or logo in a way that implies endorsement by, or
  affiliation with, the Diffo project or its maintainer.
- Register domain names, package names, social-media handles, or app-store
  listings containing "diffo" for a software product or service.

In short: **forks are welcome, but distribute them under your own name.**

[github.com/DiffoHQ/diffo](https://github.com/DiffoHQ/diffo).
